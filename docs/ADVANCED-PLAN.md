# CareerPath Advanced plan

Chosen on 6 November 2026. CareerPath aims to be a final-year quality project for students in
Andhra Pradesh and Telangana after Intermediate. The focus is showing the path, what to learn, and
how to keep up with changes in technology. Pages can be rearranged after the data is complete.

A stage is done only when it works and has been checked, not when the code exists.

## Stage 1: Core data and review

- Add the AP degree course names.
- Check the records in `PRE-CHECK.md` that could not be checked.
- Add the AP and Telangana scholarship rules.
- Add roadmaps for the 20 courses that have none.
- Publish reviewed records.

**Done when:** every checklist item in `AP-TS-COVERAGE.md` is complete or has a stated reason, and the
main records are published.

## Stage 2: Technology tracking

- First version added on 7 November 2026, with 3 changes from NIST and OWASP. They are entered by hand after reading the source. A page watcher (`scripts.watch_sources`) checks 21 official pages each time the site starts and alerts the admin. It detects that a page changed, not what that means for students, so a person still updates the record.
- Choose a small list of reliable sources.
- Save each new development with its source and date.
- Link it to the careers and skills it affects.
- Mark skills as essential, emerging, optional or outdated, with evidence for each.
- An admin reviews every change before students see it.

**Done when:** one real development can be followed from its source to an updated roadmap.

## Stage 3: Personal path

- My Course page: first version added on 7 November 2026, with no sign-up.
- Skill gap on My Course: first version added on 7 November 2026, saved in the browser.
- Show progress through milestones and projects.
- Give each recommendation a clear reason.

**Done when:** a student can choose a course and see only what matters for it.

## Stage 4: Proof and launch

- Test with a few real students, and record what helped and what didn't.
- Ask people working in each field to check the roadmaps.
- Complete a security review.
- Host the site. This needs a paid plan and a decision on student accounts.

**Done when:** the site runs online, and there are real results to show.
